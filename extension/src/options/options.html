Profile Code

The Profile Code is a public salt shared across your devices. It holds no secret, but if you lose every copy your argon2id-v2 passwords change — keep a backup.

Moving devices

Set up another device

Install Mimi on the other device, then transfer this Profile Code by QR, by .mimi-profile file, or by copy and paste. Enter the same master secret on each device — it is never stored or transferred.
