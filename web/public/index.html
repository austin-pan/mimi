Install on this device

Mimi can live on your home screen and keep working offline after your first visit.

iPhone or iPad

Open Mimi in Safari, tap Share, then Add to Home Screen and Add.

Android

Open Chrome’s menu, choose Install and create shortcut, then Install.

Computer

In Chrome, use the install icon in the address bar or choose Install page as app from the menu.

Moving to a new device? Apply your Profile Code there too. On iPhone and iPad, Safari and the installed app keep separate profile storage.
